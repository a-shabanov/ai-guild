The splash now reveals the ready interface by enlarging and fading the logo.

### Changes

- Keep the initial splash above the first loaded screen, then scale the logo from 1× to 3.2× while fading it out over 420 ms.
- Reveal the interface without blocking interaction or adding a minimum loading delay.
- Remove the splash immediately when reduced motion is enabled or the document is hidden.
- Publish versioned GitHub Releases with checked-in notes and tags targeting the exact shared version/build commit.

### Validation

Light and dark mobile browser recordings verified scale, opacity, ready task data and cleanup.
Reduced motion removed the splash without animation. All 105 tests, TypeScript and JavaScript syntax checks passed.
Native startup images keep their existing first frame; the system splash itself remains static.
Physical iPhone animation and system-launch behaviour were not tested.

View Transitions experiments are scheduled as separate local work and are not enabled in this release.
