Installed PWA screens now refresh with a downward pull while the header stays in place.

### Changes

- Show a release-to-refresh indicator below the header after a deliberate downward drag at the top of the page.
- Refresh the current screen and inbox badge without reloading the application.
- Retain task-list filters and unsent task comments through the existing data polling flow.
- Suppress elastic page/header overscroll for the captured gesture. Leave ordinary scrolling, nested scroll areas, controls, horizontal gestures and normal browser tabs to the browser.
- Cancel short or interrupted drags and prevent duplicate refresh requests while an update is pending.
- Cache the gesture module with the versioned offline shell; support Russian, English and reduced motion.

### Validation

All 11 navigation tests and TypeScript checks passed. Mobile Chromium with real touch input verified updated data, unchanged header position, gesture cancellation, horizontal/nested/ordinary scrolling, duplicate prevention, preserved search and comment drafts, Back navigation, screen changes and refresh of a screen without polling.

Physical iPhone and native WebKit elastic overscroll behaviour were not tested. View Transitions remain deferred local work.
