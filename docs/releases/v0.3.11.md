Projects now have a hierarchical wiki for shared documentation and decisions.

### Changes

- Open Wiki from a project page. Browse a collapsible page tree, breadcrumbs and child sections.
- Create Markdown pages and subpages, preview and edit content, and move pages by selecting a different parent.
- Preserve child pages when deleting a section: children move one level up.
- Detect concurrent edits with page revisions. A stale save returns a conflict and the browser keeps the local draft. Tree mutations are serialized per project to prevent concurrent moves from creating a cycle.
- Give agents the same wiki operations through REST and five MCP tools: list, read, create, update and delete pages.
- Support English and Russian UI text and mobile layouts. Refresh the PWA shell for this release.
- Record the already deployed 0.3.10 (22) runtime in source control, preserving its agent avatars and profile management, token labels, navigation and board feedback.

### Upgrade and limitations

Migration 020 adds wiki pages without modifying existing project/task records. Wiki follows the existing shared-team access model. Native iOS wiki screens, page attachments, full-text search and version history are not included. This is a server/web/PWA source release; no native store binary is distributed.

### Validation

TypeScript checks and all 139 isolated release tests passed, including REST/MCP wiki lifecycle, project renaming, cross-project and cyclic parent rejection, concurrent moves/edits, conflict detection, child preservation on deletion and cross-origin protection. Chromium checks covered first-page creation, subpages, Markdown preview, editing, moving, deletion and conflicts with draft preservation, in English and Russian and at 390px width. Physical-device validation is not included.
