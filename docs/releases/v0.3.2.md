The installed PWA restores visited tabs immediately and exposes Settings on phones.

### Changes

- Preserve visited tab content, filters and scroll while refreshing in the background.
- Add five mobile navigation tabs, client version information and an update action.
- Restore per-device Web Push subscriptions and add a real provider-delivery test.
- Refresh installed app icons through versioned URLs.
- Record the optional verification codes and device management deployed with the previous update.
- Allow deployment networking for Codex runs scoped to the tracker root.

### Validation

97 tests passed. Each commit passed TypeScript and changed JavaScript syntax checks.
Mobile widths 320–720 px, desktop navigation, the offline shell and production health/assets were checked.
Real iPhone push delivery and SMTP/Telegram verification-code delivery were not tested.

This is a source release and deployed PWA update. Native store distribution and the full on-premise installation/upgrade/restore acceptance remain separate work.
